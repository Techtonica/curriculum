# Web Patterns

## Overview
Exploring common architectural patterns used in modern web development to ensure scalability and maintainability.

## Learning Objectives
- Understand MVC (Model-View-Controller).
- Explore Repository Pattern and Service Layer.
- Understand the Singleton and Factory patterns in the context of Node.js.

## Key Patterns
- **MVC:** Separation of concerns between data, logic, and UI.
- **Dependency Injection:** Reducing coupling between components.
- **Middleware Pattern:** The core of Express.js request handling.
