# OAuth 2.0

## Overview
OAuth 2.0 is the industry-standard protocol for authorization. It allows a website or application to access resources hosted by other web apps on behalf of a user.

## Learning Objectives
- Understand the OAuth 2.0 flow (Authorization Code Grant).
- Understand the roles: Resource Owner, Client, Authorization Server, and Resource Server.
- Implement "Login with Google/GitHub" functionality.

## Resources
- [OAuth.net](https://oauth.net/2/)
- [Google Identity Platform](https://developers.google.com/identity)

## Exercise
1. Register an application in the GitHub Developer Settings.
2. Implement the OAuth flow to allow users to log in to your app using GitHub.
3. Retrieve the user's profile information using the access token.
