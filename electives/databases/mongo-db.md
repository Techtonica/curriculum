# MongoDB

## Overview
Introduction to NoSQL databases using MongoDB, a document-oriented database.

## Learning Objectives
- Understand the difference between SQL (Relational) and NoSQL (Document).
- Perform CRUD operations using MongoDB Shell or Compass.
- Understand BSON format and flexible schemas.

## Resources
- [MongoDB University](https://university.mongodb.com/)
- [MongoDB Official Documentation](https://www.mongodb.com/docs/)

## Exercise
1. Install MongoDB Community Edition or use MongoDB Atlas (Cloud).
2. Create a database for a "Blog" system.
3. Insert multiple documents into a `posts` collection.
4. Perform a query to find all posts by a specific author.
