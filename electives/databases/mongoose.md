# Mongoose

## Overview
Mongoose is an ODM (Object Data Modeling) library for MongoDB and Node.js. It provides a schema-based solution to model your application data.

## Learning Objectives
- Define Mongoose Schemas and Models.
- Implement data validation at the application level.
- Use Mongoose queries for efficient data retrieval.

## Resources
- [Mongoose Documentation](https://mongoosejs.com/docs/)

## Exercise
1. Connect a Node.js application to MongoDB using Mongoose.
2. Define a `User` schema with validation (e.g., required email, minimum password length).
3. Create a function to save a new user and handle validation errors.
4. Implement a search function using `findOne()` or `find()`.
