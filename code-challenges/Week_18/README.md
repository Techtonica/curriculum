# Week 18 — Code Challenges

### Prerequisites

1. Comfortable working with arrays, conditionals, and strings.
2. Familiar with indexing and pairing values by position.

### Motivation

These challenges practice validating strings, replacing characters, and combining related array values into a new structure.

### Learning Objectives

After finishing this folder, you will be able to:

1. Validate a string against a small set of stated requirements.
2. Transform a string by replacing selected characters with mapped values.
3. Combine values from two arrays by matching their positions.

### Sequence and Relation

- **Basic E-Mail Validation** (`Basic-E-Mail-Validation.js`)
- **Replace Vowel with Another Character** (`Replace-Vowel-with-Another-Character.js`)
- **Zip It If You Can** (`Zip-It-If-You-Can.js`)

The challenges can be completed in any order.

### Relevant Materials

1. [JavaScript 1 - Variables, Strings, Numbers](../../javascript/javascript-1-variables.md) — review for working with and transforming strings.
2. [JavaScript 2 - Arrays, Functions](../../javascript/javascript-2-array-functions.md) — review for array indexing and working with related array values.

### Common Mistakes and Misconceptions

1. In Basic E-Mail Validation, apply only the validation rules given in the exercise rather than trying to account for every rule used by real-world email addresses.
2. In Replace Vowel with Another Character, every occurrence of a vowel is replaced, not just the first: `"karachi"` becomes `"k1r1ch3"`.
