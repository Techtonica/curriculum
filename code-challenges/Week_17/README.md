# Week 17 — Code Challenges

### Prerequisites

1. Comfortable working with arrays and strings.
2. Familiar with string case.
3. Familiar with object literals and properties.

### Motivation

These challenges practice building objects from related data and checking strings for repeated characters.

### Learning Objectives

After finishing this folder, you will be able to:

1. Combine related data from two arrays into an object.
2. Build an object whose keys are array values and whose values are derived from them.
3. Determine whether a string contains repeated letters while ignoring case.

### Sequence and Relation

- **Lowercase and Uppercase Map** (`Lowercase-and-Uppercase-Map.js`)
- **Assign Person to Occupation** (`Assign-Person-to-Occupation.js`)
- **Is the Word an Isogram** (`Is-the-Word-an-Isogram.js`)

The challenges can be completed in any order. The sequence above groups the two object-mapping exercises before the separate string-analysis problem.

### Relevant Materials

1. [JavaScript 2 - Arrays, Functions](../../javascript/javascript-2-array-functions.md) — review for working with array data.
2. [JavaScript 6 - Object Literals](../../javascript/javascript-6-object-literals.md) — review for creating and working with object properties.

### Common Mistakes and Misconceptions

1. In Lowercase and Uppercase Map and Assign Person to Occupation, using a variable name after a dot creates a property with that literal name rather than the value stored in the variable.
2. In Is the Word an Isogram, repeated letters do not have to be next to each other: `"Consecutive"` repeats `"c"` without any adjacent pair.
