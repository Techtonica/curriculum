# Week 16 — Code Challenges

### Prerequisites

1. Comfortable writing functions and conditionals.
2. Familiar with strings and numbers, including string length and indexing.
3. Familiar with object literals and accessing their values.

### Motivation

These challenges practice working with values stored in objects, formatting numbers, and extracting characters from strings.

### Learning Objectives

After finishing this folder, you will be able to:

1. Calculate a total from numeric values stored in an object.
2. Format a number as a string with thousands separators.
3. Use a string's length to identify and return its middle character or characters.

### Sequence and Relation

- **Online Shopping** (`Online-Shopping.js`)
- **Return the Middle Characters of a String** (`Return-the-Middle-Characters-of-a-String.js`)
- **Format Number with Commas Separating Thousands** (`Format-Number-with-Commas-Separating-Thousands.js`)

The challenges can be completed in any order. The sequence above moves from calculating and comparing values to string extraction and numeric formatting.

### Relevant Materials

1. [JavaScript 1 - Variables, Strings, Numbers](../../javascript/javascript-1-variables.md) — review for working with strings and numbers.
2. [JavaScript 6 - Object Literals](../../javascript/javascript-6-object-literals.md) — review for working with values stored in objects.

### Common Mistakes and Misconceptions

1. In Online Shopping, an order totaling exactly $50 does not qualify for free shipping.
