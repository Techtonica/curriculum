# Week 14 — Code Challenges

### Prerequisites

1. Comfortable writing functions, loops, and conditionals.
2. Familiar with arrays and strings, including indexing and iteration.
3. Familiar with object literals and properties.

### Motivation

These challenges practice transforming arrays, strings, and objects, including extracting data, removing selected elements or characters, and comparing adjacent values.

### Learning Objectives

After finishing this folder, you will be able to:

1. Represent an object's keys as array data.
2. Remove or preserve elements based on position or content.
3. Compare adjacent values while calculating a result.

### Sequence and Relation

- **Converting Objects to Arrays** (`Converting-Objects-to-Arrays.js`)
  - A short review of working with object keys and arrays.
- **Removing Elements** (`Removing-Elements.js`)
  - Apply a position-based rule across an array.
- **String Cleaning** (`String-Cleaning.js`)
  - Remove targeted characters while preserving the rest of a string.
- **Switching Between Pencils** (`Switching-Between-Pencils.js`)
  - Compare neighboring values while calculating the total time.

The challenges can be completed in any order. The sequence above moves from transforming data to comparing adjacent values.

### Relevant Materials

1. [JavaScript 2 - Arrays, Functions](../../javascript/javascript-2-array-functions.md) — review for array indexing and manipulation.

### Common Mistakes and Misconceptions

1. In Converting Objects to Arrays, be careful not to return the object's values when the exercise asks for its keys.
2. In Removing Elements, "every second element" refers to an element's position, not whether its value is even.
3. In String Cleaning, removing all non-letter characters would also remove spaces and punctuation that should remain.
4. In Switching Between Pencils, repeated adjacent colors do not require a pencil switch, and there is no switch before coloring the first square.
