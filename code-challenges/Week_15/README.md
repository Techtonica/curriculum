# Week 15 — Code Challenges

### Prerequisites

1. Comfortable writing functions and conditionals.
2. Familiar with string length, concatenation, and case.
3. Familiar with numbers represented as strings.

### Motivation

These challenges practice comparing and transforming strings, including string length, character case, and numeric formatting.

### Learning Objectives

After finishing this folder, you will be able to:

1. Combine strings based on their relative lengths.
2. Compare two characters by letter status and case.
3. Remove unnecessary leading and trailing zeros without changing the represented value.

### Sequence and Relation

- **Short Long Short** (`Short-Long-Short.js`)
- **Check Same Case** (`Check-Same-Case.js`)
- **Remove Trailing and Leading Zeroes** (`Remove-Trailing-and-Leading-Zeroes.js`)

The challenges can be completed in any order. The sequence above moves from simple string comparison to problems with more conditions and edge cases.

### Relevant Materials

1. [JavaScript 1 - Variables, Strings, Numbers](../../javascript/javascript-1-variables.md) — review for string properties and manipulation.
2. [JavaScript 3 - Conditionals, Comparisons, Booleans](../../javascript/javascript-3-conditionals.md) — review for comparisons and conditional logic.

### Common Mistakes and Misconceptions

1. In Remove Trailing and Leading Zeroes, not every zero is removable: `"30"` stays `"30"`, and a value below 1 keeps its leading zero (`"0.5"`).
