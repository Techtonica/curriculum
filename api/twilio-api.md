# Twilio API Exercise

## Overview
This exercise introduces you to integrating third-party APIs using Twilio to send SMS and make voice calls. 

> **Note:** This content is currently under review. Please verify if the Twilio Quest program is still active or if you should use the standard Twilio Trial Account.

## Learning Objectives
- Understand how to authenticate with a REST API using Account SID and Auth Token.
- Implement programmatic SMS sending.
- Configure Webhooks for handling incoming messages.

## Resources
- [Twilio Documentation](https://www.twilio.com/docs)
- [Twilio Quickstart for Node.js](https://www.twilio.com/docs/sms/quickstart/node)

## Exercise
1. Create a free Twilio account.
2. Install the `twilio` npm package.
3. Create a script to send a "Hello World" SMS to your own phone.
4. Set up a local server using `ngrok` to receive a webhook from Twilio.
