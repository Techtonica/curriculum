# Promises-Fetch Api

You will need to create a free account with open weather map to get a key. Make sure to save your key somewhere safe, we will use the open weather map api again! Create your account [here](https://home.openweathermap.org/users/sign_up)

### Quick Guide

- Initialize the project with `npm init` command
- Install following dependencies `npm install express node-fetch dotenv ejs`
- Copy `.env.example` to `.env` and paste your own key into it: `cp .env.example .env`
- If copying content from this repo rather than cloning to a local directory, create the `index.ejs` and `server.mjs` files and copy from this repo. If you've cloned it, open those files to familiarize yourself with them.
- Start the server with `npm start`, then navigate to `http://localhost:8080/` to make the weather request.
